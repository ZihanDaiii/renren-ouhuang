# 人人都是欧皇 · 问卷拼手气红包

> 问卷 + 拼手气红包：**不填抢不到，乱填领不到。** Monad Blitz 广州 参赛项目。

在群里发红包求人填问卷，红包被抢光、问卷没人填，或者填了也是乱填。人人都是欧皇把"钱"和"认真填完"绑在一起：

1. **发布者**设定问卷、名额和总奖金，把奖金锁进 Monad 上的合约
2. **填写者**扫码答题，答完由平台的**公开质检规则**自动判定（不靠发布者人工审核）
3. 通过质检就能当场拆一个 **"保底 + 拼手气"** 红包，约 1 秒到账；填写者**不需要任何代币付 gas**
4. 没发完的奖金，发布者随时可以**全额退回**

## 为什么上链、为什么是 Monad

- **奖金托管**：奖池在合约里，发布者不能赖账；是否发钱只由公开规则和合约决定
- **分配规则不可改**：50% 平均分作保底，50% 用二倍均值法拼手气，写在合约里
- **可核对**：每一笔领取都是一笔链上交易，开奖大屏和后台都能点开核对
- **小额高频**：每个红包只有几毛钱，手续费必须接近零、确认必须快。Monad 测试网实测领取交易约 0.3–2 秒确认

## 架构

```
发布者 MetaMask ──createSurvey(奖池)──▶ SurveyRedPacket 合约（Monad 测试网）
                                              ▲
填写者手机 ──答卷──▶ Next.js API ──质检 qc-v1──▶ 签发 EIP-712 领取凭证
                    （Supabase 存答卷）          │
                                               └─ 平台中继代付 gas 提交 claim(凭证)
                                                   钱直接打到填写者的临时钱包
```

- 合约：`contracts/src/SurveyRedPacket.sol`（部署在 `0x8BFB59CefC306e6e563BFC78349eF67fa1a82458`）
  - `createSurvey` 锁定奖池（原生 MON 或 ERC-20/USDC）
  - `claim` 校验签发者签名、一人一次、答卷哈希不重复，按二倍均值法发放保底 + 拼手气，扣 5% 服务费
  - `refund` 发布者结束问卷，剩余奖金全额退回
  - 随机数 = 签发凭证时的服务端随机种子 + 区块 prevrandao，双方都无法单独操控
- 质检规则：`web/src/lib/qc.ts`，规则说明见网站 `/rules`
  - R1 一人一次 · R3 认真度小测试 · R4 最短用时（每秒 15 字的阅读速度）· R5 填空有效 · R6 直线作答（只标记）· R7 甄别题
- 页面：`/create` 发布 · `/s/[id]` 答题拆红包 · `/live/[id]` 开奖大屏 · `/admin/[id]` 发布者后台 · `/rules` 平台规则

## 本地运行

```bash
# 合约
cd contracts && forge install foundry-rs/forge-std --no-git && forge test

# 网站
cd web && npm install && npm run dev
```

环境变量见 `.env.example`。数据库表结构见 `web/supabase.sql`。

端到端测试（链上创建问卷 + 模拟认真填写和乱填）：

```bash
node scripts/e2e.mjs http://localhost:3000 0.5 5 3
```
